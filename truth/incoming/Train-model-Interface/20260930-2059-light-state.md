# light-state

**Status:** current
**Owner:** Train Model
**Provenance:** `Train_Model_Backend_Design.pdf` §5.5 (Locked) and Interfaces table, supplied by Kevin Schillinger 2026-09-30; interior/exterior elements asserted by Kevin Schillinger 2026-09-30
**Aliases:** Light State, lights state, actual light state
**Last updated:** 2026-09-30

## Definition

Two booleans, `bool[2]`, sent from the Train Model to the Train Controller. They report
the actual state of the interior lights (element 0) and the exterior lights (element 1).

## Notes

- The Train Model reflects Light Command and reports the result here. It makes no
  lighting decisions of its own; see `signals/light-command.md`.
