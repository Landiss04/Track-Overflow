# D040-plc-programs-not-required-for-first-integration

**Status:** current
**Owner:** Kevin
**Provenance:** asserted by Kevin Schillinger 2026-11-01, answering "Do PLC programs have to be fully working for the first integration (CTC-2)?": "no"
**Aliases:** CTC-2 PLC question, first integration PLC scope
**Last updated:** 2026-11-01

## Context

Harry Tye asked, while CTC-2 (the Green three-train stall) was being routed
to the Track Controller owners, whether the Track Controllers' PLC programs
have to be fully working for the first integration.

## Decision

The first integration does not require fully working PLC programs.

## Consequences

- An incomplete or faulty PLC program does not block the first
  integration. Finishing the programs stays with the Track Controller
  owners.
