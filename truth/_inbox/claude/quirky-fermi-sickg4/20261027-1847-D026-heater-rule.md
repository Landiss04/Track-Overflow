# D026-track-model-switches-heaters

**Status:** current
**Owner:** Kevin
**Provenance:** relayed by Kevin Schillinger 2026-10-20 from the Track Controller answers; switching rule by the Track Model owner (SeeingEyeTree), answers to `documents/module-owner-review.md`, commit `c92f58f`, 2026-10-26 (TM-3)
**Aliases:** track heaters, heaters, heater commands, heater control, heater threshold
**Last updated:** 2026-10-27

## Context

The system simulates track heaters that affect the track environment (SRS REQ-FUNC-022).
The Track Model ran its heaters only when commanded, while the Track Controller software
variant expected the Track Model to switch them itself, so nothing switched them.

## Decision

The Track Model switches the track heaters automatically. The Track Controller does not
command them.

A section's heater is on when the ambient temperature is at or below 0 °C, and off above
it. There is no hysteresis. If the ambient temperature is missing or not finite, the
heaters keep their last state.

## Consequences

- No heater command passes from the Track Controller to the Track Model.

## Supersedes

- Rule: previously open ("the rule by which the Track Model switches the heaters is not
  stated here"); now the single 0 °C threshold (Track Model owner 2026-10-26).
