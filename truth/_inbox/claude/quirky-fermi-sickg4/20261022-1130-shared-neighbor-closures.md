# D035-shared-neighbor-closures

**Status:** current
**Owner:** Track Controller
**Provenance:** asserted by Kevin Schillinger 2026-10-22: "Approve shared read-only neighbor closure inputs"
**Aliases:** neighbor CLOSED inputs, cross-wayside closure inputs
**Last updated:** 2026-10-22

## Decision

Track Controller waysides may read shared closure inputs for neighboring
blocks outside their own territory. These inputs are read-only; output
ownership remains with the wayside that owns the block.
