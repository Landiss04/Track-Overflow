# passenger-emergency-brake-release

**Status:** current
**Owner:** Kevin Schillinger
**Provenance:** asserted by Kevin Schillinger 2026-09-30 in the overview passenger emergency-brake bug report
**Aliases:** passenger brake release, overview emergency-brake release
**Last updated:** 2026-09-30

## Decision

The Train Model overview's passenger emergency-brake control must support
releasing the passenger brake request as well as applying it. Resetting the
entire module must not be necessary to release that request.
