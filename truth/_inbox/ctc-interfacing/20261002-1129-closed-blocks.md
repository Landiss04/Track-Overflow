# closed-blocks

**Status:** current
**Owner:** CTC Office
**Provenance:** asserted by Landis 2026-10-02 (CTC architecture diagram, `ctc-architecture.html`); types per `conventions/identifiers.md` and `conventions/units.md`, chosen by Landis 2026-10-02 over the diagram's int types
**Aliases:** Block Open / Close, block closure, closed blocks
**Last updated:** 2026-10-02

## Definition

Which blocks the dispatcher has closed for maintenance, sent from the CTC Office to the Track Controller. A block that is not closed is open.

## Notes

- Open: the diagram calls it a command (`cmd`), one open or close per block. The CTC implementation currently sends the full set of closed block IDs instead. Which form the edge carries is unresolved.
- The Track Controller owner has not confirmed it.
