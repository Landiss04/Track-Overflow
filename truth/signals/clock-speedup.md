# clock-speedup

**Status:** current
**Owner:** CTC Office
**Provenance:** asserted by Landis 2026-10-02; 10x as the only fast-forward speed asserted by Landis 2026-10-01 (proposal `truth/_inbox/generic-clock-config/20261001-1658-shared-simulation-clock.md`)
**Aliases:** clock speedup command, clock speed, speedup, fast-forward, 10x
**Last updated:** 2026-10-02

## Definition

A boolean sent from the CTC Office to the central harness: true commands the shared
simulation clock to run at 10x, false at 1x.

## Notes

- The control comes from the CTC Office. The central harness relays the command to
  the rest of the modules so that all of them run in sync.
