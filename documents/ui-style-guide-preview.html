Theme

UI Style Guide — Live Preview

ECE1140 Train Management System. Control Room Dark is the normative theme; Daylight Ops is an optional light mode for a future theme switch. Only fonts and colors change between the two — layout, spacing, sizing, and component structure are identical. The normative token tables live in documents/UI_Style_Guide.md.
