TRACK CONTROLLER — INFORMATION ARCHITECTURE & INTERACTION DESIGN
Drawn in the Jesse James Garrett visual vocabulary — structure and interaction in one continuous flow, entry point to outputs. Interface detail is deliberately absent — the wireframes carry that.
VOCABULARY USED
UNIFIED FLOW Application structure and the two core task paths, drawn as one diagram
Entry offers Program tab or View tab; either is reachable from the other at any time, so there is no fixed starting page.
Program tab: sidebar page branches to File Explorer or Previous Iteration; File Explorer can load a new file into the editor buffer. Choose controller and maintenance toggle sit alongside.
Maintenance mode is the only state from which switches can be set — it has no other manual control surface.
The output terminal updates from two independent triggers: selecting a different controller, and running the buffer.
Commit is offered only after a successful run. Confirming replaces the iteration the wayside executes and archives the previous one as a read-only file.
In the View tab, line and controller selection always resolves to the same simultaneous pair — block state and committed outputs update together.
