The Input and Output Cards are the physical I/O boundary of the PLC chassis — every signal crossing into or out of the module passes through one of them.
Raw I/O is decoded and encoded by the OS layer before the PLC program ever sees it; the program itself only ever reads and writes typed values.
Track Model and CTC are both bidirectional peers. Track Model supplies block occupancy, and receives commanded speed/authority, switch, light, and crossing states.
CTC supplies suggested speed, authority, and block open/close, and receives the same shared outputs as Track Model plus train presence on blocks. Speed limit and owned block layout are static values loaded at initial configuration.
